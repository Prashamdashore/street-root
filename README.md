# STREET ROOT 👕 

### Modern Fashion E-Commerce Website

STREET ROOT is a modern fashion e-commerce frontend project built using HTML, CSS and JavaScript.

## 🚀 Live Demo
https://prashamdashore.github.io/street-root/

## ✨ Features
- Modern and responsive user interface
- Product listing
- Product details popup
- Product size selection
- Shopping cart
- Quantity management
- Wishlist
- Product search
- Category filters
- Mobile responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
- index.html
- style.css
- script.js
